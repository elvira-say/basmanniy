# История Басманного района — мини-приложение для Telegram

Статичный сайт: `index.html` (вид), `app.js` (логика игры), `content.js` (все тексты), `images/` (картинки).
Сервер и база данных не нужны. Прогресс игрока хранится только на его телефоне.

## Как поправить текст
Откройте `content.js` и найдите нужную точку (`"n": 4` — точка 4). Меняйте только текст в кавычках.
Правильный ответ в вариантах — всегда ПЕРВЫЙ в списке, игра сама перемешивает варианты.

## Запуск (около 20 минут)
1. Зарегистрируйтесь на github.com → New repository (публичный) → Add file → Upload files → перетащите ВСЁ содержимое этой папки → Commit.
2. В репозитории: Settings → Pages → Branch: main, папка / (root) → Save. Через минуту появится адрес вида `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.
3. В Telegram откройте @BotFather:
   - `/newbot` — имя и адрес бота (например, BasmannyWalkBot);
   - `/newapp` — выберите бота, название «История Басманного района», описание, картинка `botfather_640x360.jpg`, адрес сайта из шага 2, короткое имя `game`;
   - `/setmenubutton` — выберите бота, адрес сайта, текст кнопки «Играть».
4. В `content.js` замените `https://t.me/ИМЯ_БОТА/game` на настоящую ссылку (её покажет BotFather). Это ссылка для QR и кнопки «Поделиться».
5. Счётчик (по желанию): зарегистрируйтесь на goatcounter.com, получите код, впишите в `content.js` в `"counter"` адрес `https://КОД.goatcounter.com/count`. Считаются только «старт» и «финиш», без данных о людях.
6. Проверьте игру с 2–3 телефонов БЕЗ VPN: если сайт на github.io не открывается, разместите эту же папку в российском хранилище для статичных сайтов (например, Yandex Object Storage).

Токен бота для этой схемы не нужен — никому его не передавайте.
